# homebrew-tap

Homebrew formulas for my projects.

```sh
brew install jmvezic/tap/pitwall
```

| Formula | Project |
| --- | --- |
| `pitwall` | [pitwall-tui](https://github.com/jmvezic/pitwall-tui): F1 live timing in your terminal |

The formulas in `Formula/` are written by each project's release workflow;
don't edit them by hand.
